Audio files

Upload the adhan recordings you have the right to use (mp3/m4a/ogg/wav, up to 20 MB). Files are stored in www/ajnetweb_adhan/ so speakers can fetch them.

AC pre-cooling

Start the AC a set time before a prayer, e.g. cool the majlis 30 minutes before Maghrib. An AC that is already cooler, or running as fan or dry, is left as the family set it.
