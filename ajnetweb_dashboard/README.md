# AJ Netweb Dashboard Suite

Automated room-aware Lovelace dashboard generator with 5 curated aesthetics for Home Assistant.

## Features
- **Auto-Discovery**: Rooms, lights, ACs, covers, cameras, and locks.
- **5 Aesthetics**: Cyber Luxury, Scandinavian Minimal, Modern Bento, OLED Stealth, Boutique Hotel Hub.
- **Native-First**: Built on official Home Assistant Sections and Tile cards.
- **Bundled Card Suite**: `ajnetweb-card-suite.js` (zero HACS dependencies).
- **1-Click Deployment**: Instant deployment to Home Assistant.
