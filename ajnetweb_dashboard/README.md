# AJ Netweb Dashboard Suite

Installer studio that generates a professional, responsive Home Assistant dashboard from your
Areas and Floors – one dashboard that works on phones, tablets and wall panels.

- **Responsive by design** – built on HA *Sections* views: 1 column on phones, 2 on portrait
  tablets, 3–4 on landscape tablets and wall panels.
- **Future-proof** – native HA cards + a small AJ Netweb card suite that only uses Home Assistant's
  public frontend API. No HACS, no card-mod, no forks to maintain.
- **Installer workflow** – pick theme and views, hide rooms/devices, pin favourites, add your
  support details, deploy. Re-deploy any time after adding devices; settings are kept and the
  previous layout is backed up automatically.
- **6 native themes** – Frosted Glass, Cyber Luxury, Nordic, Bento, OLED, Hospitality.
- **English & Arabic** layouts.
