# AJ Netweb Room & Guest Pass Studio

Effortless Room & Area Sharing for Home Assistant. Visual user permission matrix, zero-app guest QR codes, temporary expiring room passes, and automated Lovelace dashboard visibility.

## Features
- **Instant Guest QR Codes & WhatsApp Links**: Share specific rooms with guests, cleaners, or Airbnb tenants without downloading any app or creating accounts.
- **Visual User Room Matrix**: Check and uncheck room access for family members with zero YAML editing.
- **1-Click Dashboard Visibility Sync**: Automatically configures Lovelace dashboard views via Home Assistant's WebSocket API.
- **Scoped Security Enforcement**: Prevents guests from controlling unauthorized rooms, alarms, or smart locks.
- **Printable Welcome Smart Cards**: 1-click printable cards for guest bedrooms and vacation homes.
- **Security Audit Trail**: Logs every action executed via guest passes.
